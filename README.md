# Python DA Assignment 2 – Data Visualization

## Overview
This assignment focuses on data visualization using Python libraries. The Seaborn Taxis dataset is used for data analysis and visualization.

## Dataset
- Dataset: Taxis
- Source: Seaborn built-in dataset

## Libraries Used
- Python
- Pandas
- NumPy
- Matplotlib
- Seaborn

## Data Cleaning
- Checked missing values.
- Handled missing values using median and mode.
- Converted pickup timestamps into datetime format.

## Visualizations

### Matplotlib / Pandas
1. Line Chart – Fare Over Time
2. Bar Chart – Total Fare by Pickup Borough
3. Pie Chart – Payment Method Distribution
4. Histogram – Distance Distribution
5. Box Plot – Tip Distribution by Pickup Borough

### Seaborn
6. Count Plot – Trips by Pickup Borough
7. Scatter Plot – Distance vs Fare
8. Heatmap – Numerical Correlation
9. Pair Plot – Pairwise Relationships
10. Violin Plot – Fare Distribution by Payment Method

## How to Run
1. Clone or download this repository.
2. Install the required libraries:

```bash
pip install pandas numpy matplotlib seaborn
```

3. Open the notebook using Jupyter Notebook.
4. Run all cells.
